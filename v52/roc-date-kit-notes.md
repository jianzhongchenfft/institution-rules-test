# 共用民國日期元件（測試版 V1.2）

建立日期：2026-10-10

## 原則

本階段只新增 `roc-date-kit.js` 與 `roc-date-demo.html`；**既有登入、模組載入、資料庫、表單、日期運算與薪資結算均不修改**。

**介面與資料格式**：
- 列表／輸入：`115/10/10`。
- 月份篩選：`115年10月`。
- 正式列印：`115年10月10日`。
- 日期時間：`115/10/10 14:30`。
- SQL / Supabase：`2026-10-10`（月份 `2026-10`）。
- 時區明確的時間戳依 `Asia/Taipei` 顯示；無時區的本地時間不擅自改變。

## API（獨立於既有 rocDate/isoDate）

```js
rocDateKit.parseDate('1151010');              // '2026-10-10'（三碼年＋兩碼月＋兩碼日）
rocDateKit.parseDate('0840306');              // '1995-03-06'（補零三碼年）
rocDateKit.parseDate('840306');               // '1995-03-06'（兩碼年）
rocDateKit.parseDate('115/10/10');            // '2026-10-10'
rocDateKit.parseMonth('115年10月');             // '2026-10'
rocDateKit.parseMonth('11510');                // '2026-10'
rocDateKit.parseMonth('8403');                 // '1995-03'
rocDateKit.formatDate('2026-10-10');           // '115/10/10'
rocDateKit.formatMonth('2026-10');             // '115年10月'
rocDateKit.formatPrintDate('2026-10-10');      // '115年10月10日'
rocDateKit.formatDateTime('2026-10-10T14:30'); // '115/10/10 14:30'
```

以下 `value`、`min`、`max` 一律為西元ISO值：

```js
const field = rocDateKit.mountDate(container, {
  name: 'open_date',
  id: 'openDate',
  value: '2026-10-10',
  required: true,
  onChange(iso) { console.log(iso); }
});
field.validate();       // 驗證輸入，回傳布林值
field.getISO();         // 有效時回傳ISO，無效時回傳null；選填空白回傳''
field.setISO('2026-10-11');
field.destroy();

const month = rocDateKit.mountMonth(monthContainer, {
  name: 'salary_month', value: '2026-10', required: true
});
```

新增純數字快捷輸入：日期接受三碼年＋兩碼月＋兩碼日（七碼，如 `1151010`、`0840306`），也接受兩碼年＋兩碼月＋兩碼日（六碼，如 `840306`）。民國99年以前可加一個前導零，`0840306` 與 `840306` 都會正規化為 `84/03/06`；年份不補零顯示。月份接受三碼年＋兩碼月份（五碼，如 `11510`、`08403`），也接受兩碼年＋兩碼月份（四碼，如 `8403`），並正規化為 `115年10月` 或 `84年3月`。有分隔符號的輸入也支援 `084/03/06`。民國0年、錯誤月份及不存在的日期（如 `1150230`、`1150229`）均拒絕；不接受四位數西元年快捷輸入，亦不推測不完整或有歧義日期。

元件的隱藏輸入存 ISO 格式，且 `name` 由隱藏輸入使用；畫面上的文字輸入只接受民國年（四位數西元年會拒絕）。支援月曆／月份選擇、直接輸入、無效日期提示、選填清除、必填、上下界、鍵盤 Escape 關閉、外部點擊關閉。提供 `onChange` 讓各模組更新原有資料狀態。

## 測試

獨立開啟 `v52/roc-date-demo.html` 即可，不需登入、不會連接或寫入 Supabase。

初期程式測試已驗證：
- 民國日期輸入與西元ISO互轉、欄位內容格式化；
- 2024 閏年及 2026 平年的2月29日檢查；
- 四位數西元年誤輸入拒絕；
- 27項展示頁面純函式檢查（新增民國99年以前年份與連續數字薪資月份）；
- 直接建立日期／月份輸入元件、開啟日曆、選日期及月份、無效輸入提示；
- 含時區時間戳依臺灣時區轉換。

## 導入其他模組前須確認

1. **不得**把民國年字串直接傳入原本的資料庫 RPC 或加班／評估週期公式。
2. 將現有欄位的初始 ISO 值填入共用元件；儲存仍取 `getISO()`，且須先 `validate()`。
3. 原有 HTML `type="date"` 之讀寫事件需逐欄轉接，不宜全域替換 DOM 或覆蓋標準日期 API。
4. 需另外做實際瀏覽器測試：手機螢幕、彈出式／整頁式表單的月曆定位、鍵盤／無障礙、表單中途取消及重新開啟。
5. 月份篩選、人事／薪資等高風險模組最後導入；不要更動已驗證的日期計算規則。
6. 特殊舊日期會呈現「民前」年份；若實際使用到民前日期，需再加強日曆選年操作。

## 之後的整合方向
